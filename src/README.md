# src/ —— 你自己的设计源码

放这里的是**你写的** Verilog/VHDL，与 `raw/` 里的官方例程完全分开。

## 约定

```
src/
  top.v              顶层
  <功能模块>.v        每个模块一个文件，文件名 = 模块名
sim/                 对应的 testbench
constr/              引脚(.adc) 与时序(.sdc) 约束
```

## 为什么和 raw/ 分开

- `raw/` 是官方原件，只读，任何时候都不要改
- 例程的作用是**提供接口参考和时序范式**，不是拿来当底座改
- 官方明确要求：提交作品的**整体实现架构、音频和图片处理方法不能和参考实例相同**
  （原文见 `ai/packs/pack_00_赛题指南.md`）

所以正确姿势是：在 `ai/02_MODULE_MAP.md` 里查清例程模块的接口 → 自己重新设计架构 →
在这里写新代码 → 复用例程里可复用的**黑盒**（如 HDMI core、PLL IP）。

## 什么时候可以从例程抄代码

可以：纯工具性、无架构含义的部分，例如 `ax_debounce.v`（按键消抖）、`seg_scan.v`（数码管扫描）。
不可以：帧缓存组织方式、图片解析流程、音频嵌入方案 —— 这些是评分考察点。
